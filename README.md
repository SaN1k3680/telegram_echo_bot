# 🗣️ Telegram Echo Bot

Мой первый Telegram-бот на Python. Он отвечает на команду `/start` и повторяет любой текст, который ему отправляют (работает как эхо).

## 🎯 Что умеет бот
- Приветствует пользователя по команде `/start`
- Повторяет любое сообщение (эхо-функция)
- Работает 24/7 (если запущен на сервере)

## 🛠 Технологии
- Python 3.11
- aiogram 3.31.0 (асинхронный фреймворк)
- asyncio

## 📸 Пример использования
- Пользователь: /start
- Бот: Привет! Я живой! Это мой первый бот для портфолио 😎

- Пользователь: Как дела?
- Бот: Ты написал: Как дела?
